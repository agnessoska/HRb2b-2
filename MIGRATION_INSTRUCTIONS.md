# 🚀 Инструкция по деплою миграций Supabase

## Быстрый способ (3 минуты)

### Шаг 1: Откройте SQL Editor
Перейдите по ссылке:
https://supabase.com/dashboard/project/obcpynzcyjcdxconyzjm/sql/new

### Шаг 2: Скопируйте SQL
Откройте файл:
```
C:\Users\user\HRb2b2\HRb2b-2\supabase\migrations\combined_migration_fixed.sql
```

Выделите **всё** содержимое файла (Ctrl+A) и скопируйте (Ctrl+C).

### Шаг 3: Вставьте и запустите
1. Вставьте SQL в редактор (Ctrl+V)
2. Нажмите кнопку **Run** (или Ctrl+Enter)
3. Подождите 5-10 секунд

### Шаг 4: Проверка
Если всё прошло успешно, вы увидите сообщение "Success" внизу экрана.

## Если возникла ошибка

### Ошибка "relation already exists"
Это нормально, если вы уже запускали миграцию раньше. Таблицы уже созданы.

### Ошибка "permission denied"
Убедитесь что вы используете файл **combined_migration_fixed.sql**, а не старый combined_migration.sql

### Любая другая ошибка
Скопируйте текст ошибки и пришлите мне - разберёмся!
